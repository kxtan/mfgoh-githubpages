# May Fern Goh

Personal website, built with plain HTML, CSS and JavaScript (no build step) and hosted on GitHub Pages.

Theme: a late-night study corner. A potted fern on the desk unfurls one frond for each section as you scroll, and pulling the lamp chain switches between night and day.

## Files

- `index.html`: the whole site, including the inline desk scene
- `styles.css`: theme with night (default) and day tokens
- `script.js`: draws the fern fronds, grows them on scroll, lamp/theme toggle, active nav link
- `favicon.svg`, `resume.pdf`

## To keep up to date

- The "Off the clock" section mentions Concert 26 (12 December 2026). Update or remove it after the show.

## Publish

Push to `main`, then in the repo's **Settings → Pages** set the source to `main` / root.
The site will be at https://kxtan.github.io/mfgoh-githubpages/.
